Where your data lives

Preferred placebypassed, visibly, when it is unhealthy
Everything stays on this device; nothing is sent anywhere. Clearing browser data deletes the settings stored in the browser — keep a backup. The engine keeps its own copy of profiles and ducking rules in its config folder, so those survive a browser reset once it has connected.

Backup & restore

Imports are previewed first, de-duplicated and never silently overwrite. A damaged file imports what it can and lists what it couldn't. A backup is taken automatically before any import or reset.

Danger

Delete all local dataprofiles, options, layout, remembered levels — a backup downloads first
