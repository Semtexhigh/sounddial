macOS first launch

The build is not Apple-notarised. Right-click SoundDial.app → Open → Open, or run xattr -dr com.apple.quarantine /Applications/SoundDial.app. Per-app volume needs macOS 14.2 or newer; macOS asks for System Audio Recording permission the first time an app is tapped — that is the OS gate for reading another app's audio.

Requirements

  • macOS 14.2+ (Sonoma) for per-app control, Apple Silicon or Intel
  • Windows 10 / 11 — per-app volume is capped at 100% by Windows itself
  • Linux with PulseAudio or PipeWire (pipewire-pulse)
