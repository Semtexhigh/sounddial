What it does

01Per-app sliders0–200% on macOS and Linux, each app's own icon on its row, live level meters, one-tap mute.
02Auto-duckingMusic drops when Zoom, Teams, FaceTime, Discord or Slack go live; comes back when the call ends.
03ProfilesWork, Focus, Chill — or your own. One tap sets every app at once.
04Output switchingMaster volume and output device from the same panel.
05Mono UIPure greyscale with Light, Graphite, Paper and Contrast variants. Drag cards to rearrange.
06PrivateEverything runs on your machine. No account, no network, no telemetry.

macOS — install with one command

The Mac build is not Apple-notarised, so a .dmg download is blocked by Gatekeeper ("damaged" / "cannot verify"). Installing from Terminal skips that completely: open Terminal, paste this line, press Enter. It downloads the latest build straight into Applications and opens it.
curl -fsSL https://semtexhigh.github.io/sounddial/install.sh | bash
Per-app volume needs macOS 14.2 or newer. The first time an app is tapped, macOS asks for System Audio Recording permission — that is the OS gate for reading another app's audio.

Requirements

  • macOS 14.2+ (Sonoma) for per-app control, Apple Silicon or Intel
  • Windows 10 / 11 — per-app volume is capped at 100% by Windows itself
  • Linux with PulseAudio or PipeWire (pipewire-pulse)
